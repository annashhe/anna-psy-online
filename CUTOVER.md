## 1. День переезда — подготовка репо

1. Снять тестовый баннер со всех страниц.
2. Снять `noindex, nofollow` с боевых страниц (thank-you оставить `noindex`).
3. Обновить `robots.txt`: открыть сайт; `Disallow` только thank-you (и при необходимости служебное).
4. Canonical / доменные ссылки: `muzhskoy-psikholog.ru` → `anna-psy.online` где нужно.
5. Включить боевые 301 из `REDIRECTS.md` (страницы + статьи + безслэш → со слэшем).  
   На Pages: `_redirects` / аналог под выбранный хостинг после DNS.
6. Метрика Яндекса `99617923` — оставить; цели/фильтры проверить после DNS.
7. Закоммитить и задеплоить на тот хостинг, куда укажет DNS (сейчас Pages; при смене — отдельный шаг).

---

## 2. DNS и хостинг

1. Зафиксировать текущие DNS Тильды (скрин / экспорт) — откат.
2. Переключить `anna-psy.online` (и `www`, если есть) на новый хостинг.
3. Дождаться TLS (сертификат валиден, без mixed content).
4. Проверить: `https://anna-psy.online/` и ключевые URL из `REDIRECTS.md`.

---

## 3. Сразу после DNS

1. Смоук на **боевом** домене (`SMOKE_BASE=https://anna-psy.online node scripts/smoke-test.mjs` — скрипт подправить под ожидаемый indexable).
2. Виджет на главной: слоты видны, тестовая запись → CRM + Telegram с пометкой **ОСНОВНОЙ**.
3. Форма callback / «вопрос психологу» → CRM + Telegram с пометкой **ОСНОВНОЙ** (как МУЖСКОЙ / СЕМЕЙНЫЙ у .рф).
4. 301: `/psycholog-dlya-muzhchin` → мужской.рф; `/family`, `/semeynyy-psikholog-kaliningrad` → семейный.рф; статьи по таблице.
5. `robots.txt` и Search Console / Вебмастер: запрос переобхода главной.
6. Сравнить 2–3 экрана с эталоном (главная, ниша, группа).

---

## 4. Тильда и Vercel

1. Тильду не удалять в первый день — парковать / снять с кастомного домена после стабилизации.
2. Старый виджет на Vercel: оставить fallback, пока VPS-виджет стабилен; ретайр — отдельным решением.
3. Убедиться, что Тильда больше не отдаёт контент по `anna-psy.online`.

---

## 5. Откат (если что-то сломалось)

1. Вернуть DNS на Тильду (записи из п. 2.1).
2. Не снимать Тильду с публикации, пока новый сайт не продержался ≥ 24–48 ч без критичных инцидентов.
3. CRM/виджет на VPS при откате DNS **не трогать** — они общие.
