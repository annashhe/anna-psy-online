## Как запускать (коротко)

1. Новый Cloud Agent → вставь промпт выше.
2. Приложи скрины **или** убедись, что агент может открыть `anna-psy.online`.
3. Лучше первой задачей: только главная + общий хедер/футер/CSS.
4. Второй задачей: остальные страницы тем же промптом + «главная уже эталон, не ломай».
